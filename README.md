# Malaysian Election Results Data Visualization

## 📌 Project Overview

This project explores and visualizes Malaysian election data using Python. By applying Exploratory Data Analysis (EDA) and data visualization techniques, the project uncovers trends in election outcomes, political party performance, candidate demographics, and voter distribution across different states.

## 🎯 Objectives

* Explore Malaysian election datasets through Exploratory Data Analysis (EDA).
* Visualize election results using different chart types.
* Analyze political party performance across states.
* Examine candidate demographics and electorate distribution.
* Generate insights from election data using Python.

## 📊 Dataset

* **Datasets:**

  * `JOHOR_2022_ELECTION_RESULTS.csv`
  * `MALAYSIA_PRN6_2023_ELECTION_RESULTS.csv`
* **Source:** Public datasets for educational and data analytics practice.

## 🛠️ Tools & Technologies

* Python
* Jupyter Notebook
* Pandas
* Matplotlib
* Seaborn

## 📈 Analysis Performed

* Winning Parties by State
* Distribution of Winning Parties Across Malaysia
* Age Distribution of Candidates
* Total Electorates by State
* Winning Majority by State
* Candidate Ages by Party
* Number of Seats Won by Each Party (Johor 2022)
* Distribution of Winning Parties in Johor
* Total Electorates by Parliamentary Constituency
* Age Distribution of BN Candidates
* Gender Distribution of BN Candidates

## 📊 Visualizations

* Bar Charts
* Pie Charts
* Histograms
* Box Plots

## 🔍 Key Findings

* Compared the performance of political parties across multiple states.
* Identified variations in electorate size and winning majorities.
* Explored candidate demographics, including age and gender distribution.
* Demonstrated how data visualization supports interpretation of election results.
